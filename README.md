# Kelyn Wong Portfolio

This is my personal portfolio website, built as a place to put everything about me in one spot. It’s meant to feel like a full round-up of who I am, what I’ve worked on, and the creative things I enjoy outside of work, rather than just a strictly technical portfolio. Feel free to check out the website at [kelynwong.github.io](https://kelynwong.github.io) or dive into the source code if you're curious about how it all comes together.

## What you’ll find here

- A short introduction to me and my background
- My work experience and education
- A project gallery with filters and project detail modals
- My interests, including photography, clay, drawings, and music
- A contact section for reaching out to me

## Built With

- Vue 3
- Vite
- Tailwind CSS
- GSAP
- Three.js
- VueUse

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
